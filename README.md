\# GitHub Trending Spider



一个爬取 GitHub Trending 页面并生成图表的 Python 小项目。



\## 功能

\- 抓取 GitHub Trending 页面上的项目名和星数

\- 保存为 CSV 文件

\- 生成 Top 10 星数的横向柱状图



\## 运行方式

1\. 安装依赖：

&#x20;  pip install requests beautifulsoup4 pandas matplotlib

2\. 运行脚本：

&#x20;  python spider.py



\## 输出

\- trending.csv：抓取的数据

\- chart.png：生成的图表
